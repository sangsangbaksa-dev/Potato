# 병맛 게임즈

초저퀄 병맛 HTML5 게임 모음. 루트(`index.html`)에서 7개 게임을 고를 수 있다.

## 배포 URL (고정)

- **공식 허브:** https://potato-ebon.vercel.app/
- 위 도메인과 아래 **경로 슬러그**는 바꾸지 않는다 (폴더명·`href`·Vercel 프로덕션 alias 포함).

| 경로 | 게임 | 장르 |
|---|---|---|
| `/meet/` | 회의 탈출: 점프맵 | 횡스크롤 플랫폼 · 3맵 |
| `/toilet/` | 복도 격투: 화장실까지 | 3 WAVE 격투 · 방광 타이머 |
| `/interview/` | 면접탑: 올라가라 감자 | 세로 점프맵 · HR 낙하 공격 |
| `/potato/` | 출근하는 감자 DX : 극한 출근 | 플래피 + 극악 rage (무사고 약 5분) |
| `/duck/` | 꽥꽥 편의점 24시 | 5초 미니게임 연속 15종 (3교대 + 사장님) |
| `/still/` | 가만히 감자 챌린지 | 움직이면 지는 게임 (5스테이지, 약 3분) · 도중에 화면이 감자 게임 등으로 바뀌는 낚시 함정 포함 |
| `/farm/` | 감자 농장 (버그 있음) | 방치형 클리커 · 의도된 버그 전시 (약 4~5분) |

각 게임은 외부 에셋 없는 단일 `index.html`.

- **버그는 의도된 기능이다.** `/potato/` `/duck/` `/still/` `/farm/` 에는 일부러 넣은 버그·함정(텔레포트, 잘못된 안내문, NaN 표시, 가짜 크래시 등)이 있다. 모두 게임 안에서만 일어나며 저장 데이터나 브라우저에는 영향이 없다.

- 소리: `/potato/` `/duck/` `/still/` 에서 `M` 키 또는 타이틀 화면의 🔊 아이콘으로 음소거 (설정은 공유)
- 클리어하면 해금: 편의점 `∞ 무한 야근 모드`, 가만히 챌린지 `🔥 지옥 스테이지(90초)`
- 메뉴 카드에 클리어 배지가 표시됨 (브라우저 localStorage)
