# 병맛 게임즈

초저퀄 병맛 HTML5 게임 모음. 루트(`index.html`)에서 3개 게임을 고를 수 있다.

| 경로 | 게임 | 장르 |
|---|---|---|
| `/potato/` | 출근하는 감자 DX : 극한 출근 | 플래피 + 극악 rage (무사고 약 5분) |
| `/duck/` | 꽥꽥 편의점 24시 | 5초 미니게임 연속 15종 (3교대 + 사장님) |
| `/still/` | 가만히 감자 챌린지 | 움직이면 지는 게임 (5스테이지, 약 3분) |

각 게임은 외부 에셋 없는 단일 `index.html`.

## itch.io 업로드
각 폴더의 `index.html`만 zip으로 묶어 Kind of project: **HTML** 로 올린다.
